What this page knows about you.

Almost nothing. The site counts visits with Cloudflare Web Analytics, which records that a page was seen, roughly where from, and how fast it loaded. It sets no cookies and keeps no record of who you are, and I can't pick you out of the count.

Nothing is stored in your browser. There are no accounts, no forms and no trackers. The fonts and the music are served from here, not from someone else's servers.

The sky shows the weather where you are. To do that, the page asks a small service of mine on Cloudflare, which already knows roughly where a request comes from. It rounds that to a square about ten kilometres across, asks Open-Meteo what the sky is doing there, and sends back only the weather. It keeps nothing: not your address, not the square. Open-Meteo never sees you, only the question about the square.

The work page asks GitHub for the current commit counts and versions of the projects on it, so GitHub sees that request the same way it would if you visited those projects yourself.

The site is hosted on Cloudflare, which keeps ordinary server logs for a short while, as any host does; I don't see those, and I don't ask for them.
